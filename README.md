# Rasad Bot (سامانه رصد)

ربات تلگرام برای جمع‌آوری انتقادات، پیشنهادات و نظرات والدین، دانش‌آموزان و اساتید مدرسه.

## امکانات
- فرم مرحله‌به‌مرحله (نام و پایه اختیاری، نظر اجباری)
- ارسال نظرات به مدیران و گروه
- پاسخ‌دهی مدیر به کاربر از داخل بات
- پنل مدیریت (/admin): لیست نظرات، آمار، خروجی CSV
- تاریخ شمسی

## نصب
```bash
python -m venv venv
venv\Scripts\pip install -r requirements.txt
copy .env.example .env
```
فایل `.env` را با توکن و آیدی‌های خودتان پر کنید، سپس:
```bash
venv\Scripts\python bot.py
```

## نکته امنیتی
فایل `.env` و دیتابیس را هرگز در گیت‌هاب قرار ندهید.
